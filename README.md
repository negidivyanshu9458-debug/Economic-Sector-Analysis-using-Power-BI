#  Economic Sector Analysis using Power BI

##  Project Overview

This project is an interactive **Power BI dashboard for Economic Sector Analysis**, designed to analyze and compare economic performance across different countries, sectors, and years.

The dashboard provides insights into key economic indicators such as **GDP, economic growth, employment, sectors, and country-level performance**. Interactive slicers and drill-through functionality make it easy to explore the data from a high-level overview to detailed country-level analysis.

##  Objectives

* Analyze economic performance across different sectors.
* Compare **India with global economies**.
* Understand GDP contribution and economic growth trends.
* Analyze employment across different economic sectors.
* Compare economic indicators across countries and years.
* Provide an interactive and user-friendly dashboard for data-driven analysis.

##  Dashboard Features

### 1. Executive Overview

The Executive Overview provides a high-level summary of the economic data using:

* **Total GDP**
* **Average Economic Growth**
* **Average Employment**
* Sector-wise analysis
* India vs World comparison
* Interactive Country, Sector, and Year filters
* Visual comparison of GDP and growth across sectors

### 2. Detailed Analysis

The detailed analysis page provides:

* Country-wise economic data
* Sector-wise performance
* GDP values
* Average employment
* Average growth
* Year-wise growth trend using a line chart
* Interactive filters for Country, Sector, and Year

### 3. Drill-Through Analysis

The project also includes a **Drill-Through page** that allows users to move from the main dashboard to a more focused country-level view.

By selecting a country, users can explore the corresponding economic information in greater detail.

## 📈 Key Metrics

The dashboard focuses on the following KPIs:

| KPI                | Description                    |
| ------------------ | ------------------------------ |
| Total GDP          | Total Gross Domestic Product   |
| Average Growth     | Average economic growth rate   |
| Average Employment | Average employment indicator   |
| Sector             | Economic sector classification |
| Country            | Country-level comparison       |
| Year               | Time-based economic analysis   |

##  Insights

The dashboard helps users identify:

* Differences in economic performance between India and global economies.
* Sector-wise GDP and growth patterns.
* Changes in economic growth over time.
* Employment differences across economic sectors.
* Country-level economic performance.
* Relationships between GDP, growth, and employment indicators.

##  Project Outcome

This project demonstrates how **Power BI can transform economic datasets into interactive and meaningful visual insights**. It combines KPI cards, charts, tables, slicers, and drill-through navigation to create an easy-to-use business intelligence solution.

The dashboard can be useful for **students, analysts, researchers, and decision-makers** who want to explore economic performance through data visualization.
